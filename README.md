# odin-recipes
Project Introduction – Basic Recipe Website

This project is a basic recipe website built using HTML. The goal is to create a simple multi-page website where the main index page contains links to several recipe pages. Each recipe page will display information such as ingredients, cooking steps, and descriptions.

Although the website will not focus on design or styling yet, it is meant to strengthen core HTML skills and understanding of how webpages are structured.

By completing this project, I will demonstrate skills such as:

Creating a basic HTML page structure (<!DOCTYPE html>, <html>, <head>, <body>)
Using headings, paragraphs, and lists to organize content
Creating links with the <a> tag to connect pages
Working with images using the <img> tag
Building multiple HTML pages and connecting them together
Understanding file organization and website structure
Practicing semantic and clean HTML coding

Overall, this project helps build a strong foundation in HTML before improving the website later with CSS for styling and better design.
